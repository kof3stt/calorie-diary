# 🥗 Дневник калорий

Годовой проект студентов магистерской программы **«Искусственный интеллект» НИУ ВШЭ**, 2026/27 учебный год.

## 🎯 О проекте

**«Дневник калорий»** - интеллектуальный Telegram-бот, который позволяет определять продукты питания по фотографии оценивать их калорийность и вести персональный дневник питания.

Пользователь отправляет фотографию еды, после чего система:

1. 🖼️ анализирует изображение;
2. 🧠 определяет продукты с помощью ML-модели;
3. 🍎 определяет пищевую ценность;
4. 🔢 рассчитывает примерную калорийность;
5. 💾 сохраняет результат в дневник;
6. 📊 позволяет анализировать историю питания.
